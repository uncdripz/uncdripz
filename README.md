# Hi, I'm uncdripz! 👋

I spend most of my time writing Python and Go, usually building CLI tools or small services that scratch an itch nobody else noticed. I care a lot about how things feel to use — the keybindings, the config files, the quiet details that make a workflow disappear into muscle memory. Lately I've been drawn to open-source projects where the goal is removing friction rather than adding features, and I keep coming back to Neovim and Docker as the places where I think hardest about that.
